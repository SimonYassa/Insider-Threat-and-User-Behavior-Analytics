🛡️ CERT r4.2 Insider Threat DetectionBehavioral Anomaly Detection & SOC Review Budget Optimization across 330k User-DaysProject Team: Alieldin Tamer | Simon Ehab | Essameldin Amr📋 OverviewEnterprise Security Operations Centers (SOCs) process millions of daily telemetry logs, making manual investigation of every event impossible. This project implements a machine learning pipeline on the CERT Insider Threat Dataset v4.2 (r4.2) that aggregates multi-source employee activity to the user-day level, models personalized behavioral baselines, and prioritizes the riskiest daily records within strict SOC analyst review budgets.🏆 Key Phase 1 ResultsDataset Scale: 4,335,799 raw events across 1,000 users aggregated into 329,987 clean user-days (521 positive insider days; 0.158% prevalence).Zero Data Leakage: Enforced a strict chronological cutoff (CUT = 2010-12-31), verified via 8 structural code assertions and an 8-run label-shuffle permutation test (0.0493 real Test PR-AUC vs. 0.0020 median shuffled PR-AUC).SOC Operational Impact: Under a Top-1% daily review budget (840 alerts out of 83,913 holdout test days), the baseline model catches 13 / 18 test insiders (36.2% Recall@Budget; 47 / 130 positive days) while saving 20,768 analyst hours (210h required vs. 20,978h for full manual review).🏗️ End-to-End Pipeline ArchitectureEnvironment & Config: Deterministic setup (SEED = 42), core working hours (08:00–18:00), corporate domain (@dtaa.com), and SOC capacity (1% review budget, 15 min/review).Ground Truth & Scenarios: Loads 70 verified r4.2 insider incidents from answers/insiders.csv across Scenario 1 (30 users), Scenario 2 (30 users), and Scenario 3 (10 users).Evidence-Based Labeling: Marks 521 non-web malicious user-days as y = 1; excludes 445 web-only days (deferred to Phase 2) and 20 compromised victim-account days.Multi-Source Log Ingestion & Audit: Processes logon.csv (854,859 rows), device.csv (405,380 rows), file.csv (445,581 rows), and chunked email.csv (2,629,979 rows) with zero duplicate IDs or broken timestamps.Daily Behavioral Feature Engineering: Aggregates 17 daily activity and temporal features (ah_logons, usb_connects, file_copies, ext_emails, email_size_log, is_weekend, etc.) into user_day.parquet.Temporal Data Splitting:Fit Split: 2010-01-01 – 2010-09-30 (189,007 user-days, 241 positives)Validation Split: 2010-10-01 – 2010-12-31 (57,067 user-days, 150 positives)Holdout Test Split: 2011-01-01 – 2011-05-31 (83,913 user-days, 130 positives)Baseline Modeling (scikit-learn Pipeline):UserBaseline: Computes per-user z-score deviations ($z = \frac{x - \mu_u}{\sigma_u + 10^{-5}}$, clipped to [-10, 10]) across 9 core features strictly on benign (y == 0) training days (expanding to 26 features).StandardScaler: Fitted strictly on training data.LogisticRegression: class_weight="balanced", tuned to C = 0.01 on validation (Val PR-AUC = 0.1309).Leakage Checks & Evaluation: Evaluates PR-AUC, Confusion Matrix, Recall@Budget, and analyst hours saved.📊 Holdout Test Performance (Jan–May 2011)Decision StrategyFlagged DaysTPFPFNTNPrecisionRecallF1-ScoreInsiders CaughtStandard Threshold (p >= 0.5)4,1511054,0462579,7370.0250.8080.04918 / 18Top 1% SOC Budget (840 Reviews)840477938382,9900.0560.3620.09713 / 18Top Risk Drivers (Model Coefficients)Positive Insider Drivers: usb_connects (+1.10), emails (+0.98), emails_dev (+0.74), is_weekend (+0.70), ext_emails_dev (+0.69)Negative Normal Drivers: email_size_log (-1.01), file_copies (-0.98), wk_logons (-0.79)📂 Repository & Artifact Structurecert-r42-insider-threat/
